# Amie Chat UI Preview

This local echo fixture demonstrates message entry, rendering, and reset.
Open `index.html` in a browser. Enter a sample message and click Send or
press Enter. The fixture echoes the text. Reset Chat clears the transcript.

The preview makes no network calls. LiveKit transport, room authorization,
and audio controls require a separate integration.
